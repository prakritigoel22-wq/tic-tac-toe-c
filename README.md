# Tic-Tac-Toe in C

A simple, two-player console-based Tic-Tac-Toe game written in C.

## Features
- Two-player mode (`X` and `O`)
- Simple 3x3 numbered grid (`1–9`) for easy move selection
- Input validation to prevent overwriting occupied boxes or entering invalid numbers
- Automatic win and draw detection across rows, columns, and diagonals

## How to Run

1. **Compile the code** using GCC:
   ```bash
   gcc game.c -o game
